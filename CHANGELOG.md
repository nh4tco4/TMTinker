# Changelog

All notable changes to TMTinker will be documented in this file.

### Added
- Work in progress for a first stable release 1.0.0

## [0.2.1] - 2026-10-23

### Added
- Graphical Turing machine editor.
- Step-by-step machine execution.
- Tape editor and visualization.
- Project import and export using JSON.
- Project test cases.
- Fixed a lot of bugs.

### Known Issues
- Some features are not fully implemented.
- Windows and macOS builds are experimental.
